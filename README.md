# Test Drive of Stare.js
Based on the template of [stare.js-client made by d-salazar-se](https://github.com/StArE-js/stare.js-client)

There are some differences, like using vite instead of parcel for better compatibility with CodeSandbox

This test drive explains in simple terms the 3 steps it takes to make Stare.js work
It uses some of the visualizations used as examples, plus the ones made for the vitrina/showcase 

## Installation

```bash
npm install
```
## How to use

```bash
npm run start
```

Now you can point your browser to

```
http://localhost:5174/
```
